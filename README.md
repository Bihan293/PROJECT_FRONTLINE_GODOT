# PROJECT FRONTLINE — Godot 4 Mobile Edition

Тактический 3D FPS шутер для Android, созданный на движке **Godot 4** в стиле Dummy War:
* **Честная нативная производительность:** Работает на C++ движке Godot 4 с рендерером `gl_compatibility` (Vulkan / OpenGL ES 3.0), обеспечивая плавные 60-90 FPS на мобильных устройствах.
* **Анатомические солдаты-манекены:** Проработанные бойцы с шарнирными конечностями, процедурной анимацией походки и тактической стойкой.
* **Физический Рэгдолл (Ragdoll):** При гибели солдаты отлетают от силы выстрелов, суставы гнутся, шлемы срываются при хедшотах.
* **Система крови:** Направленные 3D-брызги крови и устойчивые лужи на земле.
* **Сенсорное управление:** Виртуальный джойстик слева, свободный мультитач-обзор справа, кнопки стрельбы, зума, перезарядки, приседа и бинтов.
* **Режим игры:** Захват 3 тактических точек (A, B, C) в деревне, союзные и вражеские боты с выбором численности (6v6, 10v10, 16v16, 24v24).

## 🎮 Управление:
* **Левая часть экрана:** Виртуальный аналоговый джойстик (ходьба).
* **Правая часть экрана:** Плавный обзор камеры.
* **ОГОНЬ** — стрельба из текущего оружия.
* **ПРИЦЕЛ** — тактическое приближение (зум).
* **ПРЫЖОК** и **ПРИСЕСТЬ** — управление высотой и укрытиями.
* **ЗАРЯД** — перезарядка магазина.
* **БИНТ** — остановка кровотечения и лечение.
* **Слоты АК / ДРОБ / СВ / ПМ** — мгновенное переключение арсенала.
